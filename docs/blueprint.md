# **App Name**: ToolboxHQ

## Core Features:

- Homepage Display: Showcase available tools with brief descriptions.
- Image Compressor: Compress images to reduce file size without significant quality loss.
- Image Cropper: Crop images to specified dimensions or aspect ratios.
- About Section: Provide information about the ToolboxHQ project, its goals, and the team behind it.
- Contact Form: Enable users to submit inquiries or feedback via a contact form.
- AI-Powered Tool Recommendation: An AI tool recommends new digital tools to add to the website, based on user feedback and trends, that might improve the website experience. The LLM uses an existing database of digital tools as a tool.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to convey trust and professionalism.
- Background color: Very light grayish blue (#F0F4F8) for a clean and modern look.
- Accent color: Orange (#FF9800) to highlight important calls to action and interactive elements.
- Body font: 'PT Sans', sans-serif, for clear, readable text.
- Headline font: 'Space Grotesk', sans-serif, for modern and engaging titles; for longer text use 'Inter'.
- Use minimalist, vector-based icons to represent different tools and functionalities.
- Use a grid-based layout to ensure consistency and responsiveness across devices.
- Incorporate subtle transitions and animations to enhance user experience (e.g., fade-in effects, loading spinners).
